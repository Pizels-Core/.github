# Pizels Core

Building the core tooling behind Pizels: native, fast, and small.

## What we work on

- **Desktop**: native desktop app (Rust)
- **Studio**: creation and editing environment (TypeScript)
- **Reader**: low-level reader library (C)
- **Generator**: low-level generator library (C)
