## Why Pizels Core

We build the foundation first. Instead of stacking frameworks, we write the low-level pieces ourselves, so everything on top stays fast, predictable and ours to shape.

## The stack

| Layer | Built with | Role |
|-------|-----------|------|
| 🖥️ **Desktop** | Rust | Native app that puts everything in your hands |
| 🎨 **Studio** | TypeScript | Where things get created and edited |
| 📖 **Reader** | C | Low-level engine that reads and understands data |
| ⚙️ **Generator** | C | Low-level engine that produces it |

## Where we are

Most of our work is happening **behind closed doors** for now. We would rather ship something solid than something early. Public releases, docs and demos will land here as each piece is ready.
